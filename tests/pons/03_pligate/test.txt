*define
mode_ext
game
*start
; ===========================================================================
; PONScripter h_ligate: the substitutions Le sanglot des cigales relies on.
;
; SOURCE LINES ARE THE GAME'S OWN, verbatim from its pscript.dat. In them the
; ligature source sequences are ordinary VISIBLE GLYPHS, which is what makes
; this test golden-free and unambiguous:
;
;   %-  -> U+2011  (non-breaking hyphen)  fails => a stray '%' appears
;   %.  -> U+2009  (thin space)           fails => a stray '%' appears
;   -!- -> U+2014  (em dash)              fails => '-!-' appears literally
;
; Assertion, visual, no reference image needed: no rendered case may contain
; a '%', and the -!- case may not contain '-!-'. '%' and '!' are both real
; glyphs in the font, so a failed substitution is unmissable.
;
; Definitions are sanglot's own define block (order preserved; the trie is
; LIFO, so 'basic' comes first and multi-character sequences after it).
; Clickwaits (@) and voice tags (~n~/~u~) are stripped from the source lines:
; the first would block the page, the second renders no text here.
; ===========================================================================
bg #000000,0
repaint
texton
h_ligate basic
h_ligate "%_", 0x00a0
h_ligate "%.", 0x2009
h_ligate "%-", 0x2011
h_ligate "fi", 0xfb01
h_ligate "fl", 0xfb02
h_ligate "--", 0x2013
h_ligate "-!-", 0x2014
; --- 1_pct_hyphen (pscript.dat line 1141) ---
^ Mais pourquoi tant d'excuses%.?
textshow
repaint
snapshotsave "pl_1_pct_hyphen"
textclear
; --- 2_pct_space (pscript.dat line 1177) ---
^ À qui peut%-elle bien demander pardon%.?
textshow
repaint
snapshotsave "pl_2_pct_space"
textclear
; --- 3_emdash (pscript.dat line 1200) ---
^-!- Keiichi, on va bientôt arriver. Allez, réveille%-toi.
textshow
repaint
snapshotsave "pl_3_emdash"
textclear
; --- 4_pct_fused (pscript.dat line 1308) ---
^-!- Combien tu veux de riz, un bol%.? Un demi%-bol%.?
textshow
repaint
snapshotsave "pl_4_pct_fused"
textclear
; --- negative control: `pligate none` clears every definition ----------------
; Case 3's EXACT source line, rendered with no ligatures active. The '%' and the
; '-!-' MUST be visible here. That is what proves the cases above are really
; exercising the substitution rather than removing the markers some other way.
pligate none
^-!- Keiichi, on va bientôt arriver. Allez, réveille%-toi.
textshow
repaint
snapshotsave "pl_5_control_none"

^ PLIGATE DONE
textshow
repaint
snapshotsave "pl_done"
